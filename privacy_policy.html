Privacy Policy for Instagram Graph API Test Usage

This privacy policy describes how test data is handled when using the Instagram Graph API for development or demonstration purposes only.

Information Collected

For this test-only implementation, the following information may be collected from Instagram Graph API responses:

  • Public profile data such as username and profile picture.
  • Public media details including captions, media type, and timestamps.
  • Basic engagement metrics if available in API responses.

Use of Information

The information is used solely for testing, debugging, and verifying integration with the Instagram Graph API. It is not sold, shared, or used for marketing purposes.

Data Retention

Test data is retained only as long as needed for development and may be deleted or reset periodically to maintain a clean test environment.

Security

Reasonable measures are taken to protect test data from unauthorized access. This includes storing API tokens and responses in a controlled environment and limiting access to authorized developers.

Third-Party Access

No third-party services are granted access to the test data except for the Instagram Graph API itself and any tools explicitly used for debugging and development.

Disclaimer

This policy is intended for testing and demonstration only. It does not represent a full production privacy policy and should not be used as legal documentation.

If you have questions about this test privacy policy, contact the development team responsible for the application.
